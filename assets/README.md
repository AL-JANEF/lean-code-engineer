# Brand Assets

## Idea

The brackets represent software boundaries. The shrinking center path represents progressive disclosure: less context as the decision becomes more precise. The check mark represents evidence-backed completion.

## Palette

| Name | Hex | Use |
|---|---|---|
| Deep teal | `#143C3A` | Primary field and trust |
| Emerald | `#16A085` | Active accent and progress |
| Mint | `#B8E986` | Verification highlight |
| Soft white | `#F4F8F6` | High-contrast text |
| Violet | `#8B7CF6` | Rare ecosystem accent only |

## Files

- `icon.svg` — square application and skill icon.
- `logo.svg` — self-contained horizontal wordmark for light or dark GitHub themes.
- `social-preview.png` — 1280×640 repository social image with left-side negative space for GitHub overlays or later campaign copy.

Keep clear space around the icon equal to one bracket stroke. Do not recolor the check mark red, stretch the wordmark, or add detailed artwork at icon sizes.

The social preview background was generated with the built-in image-generation tool, then resized without changing its 2:1 composition. Prompt intent: a text-free, premium teal technology field with progressive bracket layers, a secure center, right-weighted geometry, and clean space on the left; no trademarks, UI, people, devices, watermarks, or code text.
