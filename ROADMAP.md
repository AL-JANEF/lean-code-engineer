# Roadmap

The roadmap is evidence-driven. Dates are intentionally omitted until maintainers and compatibility environments exist.

## 0.1 — Foundation

- Lean core, conditional references, domain modules, safe tooling, tests, docs, and identity.
- Claude Code plugin and standalone installation paths.
- Experimental Codex metadata and installer adapter.

## 0.2 — Behavioral evidence

- Run blinded evaluations on bug fixes, features, refactors, and security-sensitive tasks.
- Measure route precision, unnecessary file loading, completion quality, and regression rate.
- Publish reproducible fixtures and baseline results.

## 0.3 — Ecosystem adapters

- Add Cursor and OpenCode adapters only after host contracts and invocation behavior are tested.
- Add host-version compatibility tests and clear degradation behavior.

## 0.4 — Modular releases

- Version domain modules independently when their maintenance cadence justifies it.
- Add community module acceptance and deprecation criteria.

## 1.0 — Stable contract

- Freeze the core priority model and routing contract.
- Publish migration guarantees, signed release artifacts, and a maintained support matrix.
